# Škola v přehledu

Veřejná statická aplikace bez vložených osobních dat. Soubor JSON se importuje lokálně a změny se ukládají pouze v prohlížeči. Přenos mezi zařízeními: Export → Import. Bez automatické synchronizace s EduPage.

Výsledky jednotlivých úkolů a čtvrtletní hodnocení jsou oddělené; aplikace nepočítá průměr.

Do této složky ani do historie veřejného repozitáře nepatří vyplněná data, exporty, screenshoty či komentáře učitelů.
